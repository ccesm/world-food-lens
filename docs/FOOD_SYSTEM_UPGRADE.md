## 公式与含义

### 历史百分位

`P = 100 × (历史中小于当前值的数量 + 0.5 × 等于当前值的数量) / N`。
只用当前观测**之前**的参考值，平局中秩处理。不填补缺失月份。

- 库存分：三种谷物各自的 `100 − 库存消费比百分位`，等权平均。
  参考 2000 年起至上一个市场年度；至少 10 个历史年度。
- 成本分：World Bank Brent、尿素、DAP、氯化钾四个名义价格水平
  百分位的等权平均。每项参考此前最多 120 个月，至少 36 个月。
  不是成本同比涨幅、战争强度或经过因果估计的传导系数。
- 价格分：FAO 名义指数在此前最多 120 个月的水平百分位。
  同时单独展示同比。不是期货突破、消费者食品通胀或实体短缺确认。

拟定权重：多产区作物压力 25%、库存 20%、进口需求 15%、
能源化肥 15%、贸易物流 10%、价格 10%、关键窗口同步受压 5%。

`总分 = Σ(因子分 × 权重 / 100)`，**仅在七项都有合格证据时显示**。
当前仅库存、成本、价格三项接通，可计分权重为 45%。
`已知贡献 / 45` 不是危机总分，也不重新缩放成 100 分。
数学上下界把未知因子设为 0 或 100，不是置信区间。
分级：≤20 低、>20–40 中等、>40–60 偏高、>60–80 高、>80 严重。
建议档案示例中的 48.75 按其给定刻度应为“偏高”，而不是“中等”。

上述权重是实验筛查规则，没有用危机样本拟合或验证；不输出危机概率，
不声称量化的“1972 相似度”。价格水平分位未经通胀调整，历史有修订；
月度价格和年度供需不是同步高频观测。

刷新失败、72 小时未检查、月度发布期超过 100 天或未来时间戳的来源
不参与当前计分。旧缓存继续在原有模块展示并明确标注状态。

### 季节与冻害

P 播种/出苗 40、V 营养生长 45、W 越冬 70、F 开花/授粉 95、
G 灌浆/结荚籽粒形成 85、H 成熟/收获 25、季节之外 0。
这是本站为界面排序设定的通用敏感度，**不是官方系数、产量损失或风险概率**。
F/G/W 被列为关键检查窗口。相同敏感度按记录编号稳定排序。
本月清单最多展示八项，完整记录在可筛选的年度日历中。

尚未具备地方天气、产区份额与出口权重，因此不实现乘法天气风险分，
不称清单为全球风险排序。越冬阶段尤其要结合冠部温度而非只看气温。
冻害检查只有四项均明确为“是”才显示联合暴露；未知不是“否”，
没有同时满足也不等于安全。缺少积雪/土温/抗寒/冰壳资料时不输出冻死概率。

## 数据与权限清单

“已接通”指每日流水线下载的官方观测缓存，不是实时行情。

| 来源 | 已有或新增内容 | 状态 / 密钥 |

| [NOAA CPC](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso/roni/) | RONI 观测 | 已接通，无密钥；不能代替地方天气 |
| TradingView | 原有 12 个投资标的公开嵌入图表 | 不抓取其行情用于新评分；保留归属与延迟说明 |
| USDA 正常作物日历 / FAO 日历 | 代表性季节背景 | 本站模板全部 `sourceType: estimated`，不是自动同步或今年实测进度 |
| 政策事件和发布日历 | 既有精选历史记录 / 已确认和预计发布日期 | 人工核对，非实时政策状态 |

没有新增需要用户输入凭证的接口，没有请求券商账户权限。
未来卫星、天气、贸易和物流接口尚未选定，授权、限流和许可需要逐项确认，
不是假设它们都必须付费或都需要 API key。

季节模板的来源与语义边界：

- [USDA 正常作物日历](https://ipad.fas.usda.gov/pdfs/crop_cal.pdf)：作物阶段背景；
  UI 的月度范围为本站近似编排，不宣称每个格子为官方发布值。
- [USDA 巴西玉米日历](https://ipad.fas.usda.gov/highlights/2013/05/br_15may2013/BrazilCornCropCalendar.htm)：
  巴西二季玉米背景参考。
- [FAO Crop Calendar](https://cropcalendar.apps.fao.org/)：后续按农业生态区细化的候选来源，尚未自动导入。
- [K-State 越冬说明](https://eupdate.agronomy.ksu.edu/article_new/snow-cover-temperatures-and-wheat-condition-436-1)：
  冠部/土壤温度与积雪的重要性，不作为全球统一数值阈值。
- [USDA ERS 历史回顾](https://www.ers.usda.gov/amber-waves/2009/march/agricultural-commodity-price-spikes-in-the-1970s-and-1990s-valuable-lessons-for-today)：
  1972–1974 案例；没有未经核实地重现逐月苏联冻害链条。

旧站恢复快照继续作为原有模块的最后回退；新评分不使用它。
新模块没有随机数据或伪造的实时值。未知因子是明确的未完成功能，不是模拟观测。

## 未完成与建议顺序

1. 用可授权的官方地区降雨、土壤水分/温度、积雪和作物评级，建立
   至少一个完整作物季节的验证样本；替换通用日历为地区级记录。
2. 引入国家/地区生产和出口份额，避免把季节敏感度误当全球重要性；
   然后才计算天气与关键窗口同步压力。
3. 引入同口径月度进口或招标数据、当前有效政策与航道状态。
   当前没有进口加速、霍尔木兹/红海实时评级、11 项模式匹配或全球红绿地图。
4. 创建发布版本归档，在真实“当时可见”数据上验证权重和误报率。
5. 人口需求、总谷物/其他库存持有国对照、1959–1961 中国历史案例、
   更广泛地区覆盖与资产相关性仍为后续工作，本次没有假装全部完成。
