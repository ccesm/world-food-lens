## 2. 第一份真实数据的合理性检查

发布 `a443b98`（run 37681445891）。窗口为 2026-09-22 至 2026-10-05，范围是十个州、2023 年制图玉米面积，**不区分生育期**。
覆盖率 0.99999999（与 Level C 相同），所有州都可用，`baseArtifact.analysisHash` 与同一次运行的 `corn-spatial.json` 一致。

| 指标 | 面积加权平均 | p50 | p90 | 最大 |
| --- | --- | --- | --- | --- |
| EDD，29°C 基准（°C·日） | 0.14 | 0 | 0.33 | 4.14 |
| EDD，30°C 基准（°C·日） | 0.07 | 0 | 0.11 | 3.07 |
| Tmax ≥ 35°C 天数 | ≈0 | 0 | 0 | 2 |
| 最长连续高温日 | ≈0 | 0 | 0 | 2 |

各州面积加权的 EDD29 平均值（最大值）：
- IL 0.47（4.14）
- MO 0.45（4.14）
- IN 0.33（1.85）
- OH 0.16（0.77）
- KS 0.08（1.72）
- NE 0.01（0.69）
- IA、MN、SD、WI 均约为 0

只有 IL 和 MO 出现了高温日，最多 2 天。

检查结论：
- 时值秋季，绝大部分面积的 EDD 为 0，热量集中在偏南的州，这与季节和地理一致。
- 所有州的 EDD30 都不大于 EDD29，符合定义。
- Level C 同一窗口记录的期内最高温为 35.8°C，与"个别格点出现 ≥ 35°C 高温日"一致。
- 这只是合理性检查，不是对准确性的验证。不能用来说明热害、减产或风险高低。

## 4. 已知局限

- EDD 是由日最高温和最低温重建的 single-sine 近似值，不是逐时积分。
- 不区分生育期；2023 年地图是替代；不区分灌溉与雨养。
- 14 天窗口，没有季累计（2.1b 待评估）。
- 35°C 是 WFL 自定的阈值（C 级），不是生理伤害界限。
